# Code of conduct setup

Before publication, choose a recognized full policy, for example an appropriate current Contributor Covenant version, preserve its license/attribution, and publish it as CODE_OF_CONDUCT.md with an actual private enforcement contact.

Define who receives reports, how conflicts involving that person are escalated, what privacy can realistically be offered, and how enforcement decisions are handled. Obtain the moderators' agreement. Do not publish a dead address or pretend this checklist is the complete code of conduct.

Reference: [Contributor Covenant](https://www.contributor-covenant.org/).
