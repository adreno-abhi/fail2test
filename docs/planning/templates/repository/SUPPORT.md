# Support

- Reproducible bug: open an issue with version, supported environment, synthetic reproducer and redacted output.
- Usage/design question: use GitHub Discussions if enabled; otherwise use a clearly labeled question issue.
- Feature request: describe a real workflow, current workaround and acceptance example.
- Vulnerability: use the private route in SECURITY.md.
- Conduct concern: use CODE_OF_CONDUCT.md's private enforcement route.

Open source support and reviews are best effort. No response-time or availability SLA is implied. Commercial services, if introduced, will have separate clearly stated terms; using the local open source project does not require buying support.

Never upload customer traces or credentials to obtain help. Start from a synthetic case or a reviewed sanitized export.
